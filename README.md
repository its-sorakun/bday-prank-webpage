# A birthday prank website

built on reactjs using vite.

I am not including much technical details as its just a fun project which won't be maintained for long.

Architecture details:

This project is built as a single-page application using React and Vite.
It follows a state-machine architecture where the user progresses through different "stages" of the prank.

The user journey is structured as a progressive linear gauntlet rather than a traditional navigable website. Each stage acts as an interactive roadblock designed to subvert user expectations—starting with a mandatory "Terms of Existence" banner featuring a touch-evasive decline button, proceeding through an unwinnable sleep-schedule verification challenge, and running into immortal cake candles that refuse to stay extinguished. The gift reveal takes inspiration from gacha mechanics, simulating a 50/50 banner loss to Qiqi before triggering an authentic vintage operating system crash screen.

Aesthetically, the project intentionally avoids modern design trends such as glassmorphism in favor of chaotic early-2000s desktop retroism, Windows-style beveled dialogs, and mobile-friendly touch traps. Once the simulated crash sequence reboots, the application locks into its celebratory finale state: an interactive digital shrine dedicated to user, featuring real-time confetti, an official certificate of aging, and humorous milestones commemorating the transition into unc status.

## Setup & Running Locally

### Prerequisites
- Node.js (v18 or newer)
- npm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
